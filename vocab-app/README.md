# 乐词 · 免费背单词

一个纯网页版背单词 App，对标「不背单词」的核心学习体验：**完全免费、无任何功能限制、无需联网、无需安装**。

## 手机 App（Android / iOS）

### Android：安装 APK（推荐）
已构建好的安装包：`D:\Project\zcode\乐词背单词-v1.0.0.apk`（约 5MB）
1. 把 APK 传到安卓手机（微信文件传输/数据线/网盘均可）
2. 手机上点击安装（需允许「安装未知来源应用」）
3. 装完即是独立 App：桌面图标、全屏运行、状态栏/手势条适配、深色模式跟随系统、系统级 TTS 朗读

> **模拟器用户注意（MuMu/雷电等）**：部分模拟器不带 TTS 语音引擎，App 会自动改用**在线发音**（需网络）；离线时可在模拟器应用商店安装「Google 文字转语音」等引擎获得离线朗读。已用 MuMu（Android 12）实测通过。

自行构建：用 Android Studio 打开 `vocab-android` 工程点 Build 即可；命令行构建见下。
```
cd vocab-android
gradle assembleRelease   # 使用 Android Studio 自带 JDK 与本地 Gradle
```
修改网页代码后：运行 `python vocab-android/copy_www.py` 同步进工程，再重新构建。

### iOS：PWA 添加到主屏幕
Windows 无法编译 iOS 安装包（需要 macOS + Xcode + 开发者账号），提供标准 PWA 方案：
1. 手机与电脑连同一 Wi-Fi，电脑上启动本地服务：
   `cd vocab-app && python tools/serve.py`（默认 8765 端口）
2. iPhone Safari 打开 `http://电脑局域网IP:8765`（电脑 IP 用 `ipconfig` 查看）
3. Safari 分享按钮 → **添加到主屏幕** → 获得全屏 App：独立图标、无浏览器地址栏、离线缓存（Service Worker）、状态栏适配
4. 或者把 `vocab-app` 文件夹部署到任意静态托管（GitHub Pages 等），以后随时随地说开就开

> PWA 在 Android 上同样可用（Chrome 菜单 → 添加到主屏幕）。

## 快速开始（电脑）

**双击 `index.html`** 即可在浏览器（推荐 Chrome / Edge）中使用。

- 手机上使用：把整个 `vocab-app` 文件夹传到手机，用浏览器打开 `index.html` 即可（或用电脑浏览器打开后按 F12 切换手机视图）。
- 学习数据保存在本地。**跨版本自动继承**：每次学习后自动写三份快照——App 私有目录（覆盖安装必定保留）、媒体库副本 Pictures/乐词备份（卸载重装后授权媒体权限即可自动恢复）、localStorage（网页端兜底）。重装/清数据后首次打开若检测到空库会自动恢复进度并提示；Android 首次启动会请求一次「照片和媒体」权限用于读取该备份。覆盖安装更新无需任何操作，数据直接继承。仍建议重要节点「我的 → 导出学习数据」做手动备份。

## 功能

### 背词核心（v1.2 支持断点续学）
- 学到哪存到哪：每个词完成即保存进度，中途退出后再次打开**从断点继续**（同一队列同一位置）
- **学新词**：先自评（认识/模糊/忘记了，释义模糊遮挡）→ 展开完整释义；每学 5 词插入一次小测验，答错自动重讲重测
- **拆词助记**：单词按音节分块着色；详情含词缀拆解、词书记忆法、同根词、近/反义词、常用短语（完整显示不截断）
- **例句朗读**：每个例句可单独朗读；例句中的单词点击即查（底部小卡片：音标/释义/收藏/详情）
- **学新词**：单词按音节分块着色（助记发音拼写），卡片含美/英音标 + 自动发音 + 词性释义 + 真题例句；每学 5 词一组 4选1 测验，答错自动重讲重测
- **拆词助记**：详情页「拆词助记」区自动展示词缀拆解（前缀/词根/后缀分色 + 含义，如 ab-离开 + sol-太阳 + -ly）、词书记忆法（40%+ 词覆盖）、同根词、近/反义词、常用短语
- **记忆曲线复习**：10分钟 → 1天 → 2天 → 4天 → 7天 → 15天 → 30天 → 60天，通过全部间隔才「已掌握」毕业；复习队列按到期时间排序（最该见的词最先），复习答错自动回炉；词表页每行显示下次见面时间（待复习 / N小时后见 / N天后见）；答完题题目区收起，详解装进独立小窗（窗内滚动、主界面固定），点击选项可切换查看对应单词
- **拼写练习**：对今日新学 / 生词本 / 学习中的单词听写，可逐字母提示
- **生词本**：学习中点 ★ 收藏（存入当前选中的生词本）；错词可自动收进生词本（设置可关）

### 速刷与测试
- **备考速刷（翻面式）**：正面只显示单词，点击卡片翻出释义/例句/拆词助记（详解在独立小窗内滚动），底部三键自评（不认识/模糊/认识）；**模糊与不认识的词自动加入当前生词本**，不干扰记忆曲线
- **掌握测试**：随机 20 词混合题型（看词选义/看义选词/听音辨词/真题例句填空），出报告（掌握得分 + 错词列表 + 一键收藏）
- **多生词本**：可新建/删除多个生词本（如"高频词""易混词"），收藏时存入当前选中的生词本，删除本子不丢词

### 数据与个性化
- **仪表盘**：词书进度卡（已学/总词数/生词本）、今日学习&复习、累计学习、今日/累计时长、周日历签到、每日学习量柱状图、月打卡日历
- **词库管理**：内置词库一键切换（进度互相独立）；导入自定义词库（TXT / CSV / JSON，模板见「词库导入模板」文件夹）
- **高频词**：内置 COCA 词频数据，可按「COCA 前 5000 / 8000」筛选学习范围、按高频优先排序
- **乱序学习**：学新词、速刷默认乱序取词（可在设置中改为词书序/高频优先）
- **词表页**：词库卡片点开即进入全屏词表——按 全部/未学习/复习中/已掌握/已标熟 筛选，眼睛按钮一键隐藏释义自测，底部工具条支持 速刷 / 随身听（逐词自动朗读循环）/ 听写 / 导出词书（TXT）
- **电脑快捷键**：数字键 1-4 选选项 / 空格发音 / Enter 继续 / Esc 退出
- **深色模式**：关 / 开 / 跟随系统
- **设置**：每日新词数（5-300）、美音/英音、自动发音、学习顺序（默认乱序）、学习范围、错词自动收藏、深色模式、数据导出/导入备份

## 常见问题

- **进度会丢吗？** 存在本地（浏览器 IndexedDB / App 存储）中，正常使用与覆盖安装更新都不会丢。卸载重装、清浏览器数据前请先「导出」备份，装好后「导入」恢复。
- **没有声音？** 检查系统音量与浏览器自动播放策略；首次点击发音按钮后浏览器会放行后续语音。
- **能背雅思/托福吗？** 可以，把词库文件（TXT/CSV/JSON）导入即可。
- **拆词助记/记忆法不是每个词都有？** 记忆法来自词书原始数据（约 40% 覆盖），词缀拆解与音节划分为程序自动生成，覆盖不全属正常。
- **高频词筛选对自定义词库无效？** 是，COCA 词频只匹配到了内置词库的词。
