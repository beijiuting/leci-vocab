【自定义词库导入说明】

一、支持的文件格式
  1. TXT / CSV —— 每行一个单词，格式：
        单词[分隔符]词性[分隔符]释义
     · 分隔符自动识别：Tab、逗号、分号均可
     · 只有单词也可以（释义可省略，测验会自动改用「听音选词」）
     · 以 # 或 // 开头的行会被忽略
     示例：
        abandon	v.	放弃；抛弃
        ability,n,能力；才能
        honest

  2. JSON —— 数组，元素支持三种写法：
        "honest"                                      （只有单词）
        { "word": "ability", "meaning": "能力；才能" }   （简单释义）
        { "word": "abandon", "us": "美音", "uk": "英音",
          "trans": [ { "pos": "v", "tranCn": "放弃" } ],
          "sentences": [ { "en": "例句", "cn": "翻译" } ] }   （完整数据）

二、导入步骤
  1. 打开 App，进入「词库」页
  2. 点击下方「点击选择文件导入」
  3. 选择 TXT / CSV / JSON 文件
  4. 导入成功后可预览词表，并一键切换到该词库

三、注意事项
  · 重复单词会自动去重（不区分大小写）
  · 词库之间学习进度互相独立，可随时切换
  · 自定义词库可在词库页删除
  · 本文件夹中的模板文件可直接用 Excel / 记事本打开编辑
