# iOS 安装指南（乐词 · 免费背单词）

## 先说清楚：iOS 的两种「装法」

| 方式 | 得到什么 | 需要什么 |
|------|----------|----------|
| **PWA 添加到主屏幕（推荐）** | 独立图标、全屏无地址栏、加到桌面即用 | 只需 iPhone + 本指南，**5 分钟搞定，免费** |
| 原生 App Store / IPA | 真正的原生安装包 | 必须 **Mac 电脑 + Xcode + 苹果开发者账号（688元/年）**，Windows 上无法编译（苹果的硬性限制） |

Windows 用户给 iOS 交付应用的业界标准做法就是 PWA（渐进式 Web 应用）。本应用已完整适配：
图标（apple-touch-icon）、全屏独立运行、状态栏/刘海安全区适配、离线缓存（部署到 https 后自动生效）。

---

## 方式一：家里 Wi-Fi 直接用（最快，5 分钟）

前提：iPhone 和电脑连**同一个 Wi-Fi**。

1. 电脑上启动本地服务器（在 `vocab-app` 目录）：
   ```
   python tools/serve.py
   ```
   窗口会显示一个「手机地址」，例如：`http://192.168.1.100:8765`

2. **iPhone 用 Safari**（必须是 Safari）打开该地址

3. 点 Safari 底部「分享」按钮（方框加箭头）→ 向下滑找到 **「添加到主屏幕」** → 点「添加」

4. 桌面上出现「乐词」图标，点开就是全屏 App（无地址栏），和普通 App 一样使用

> 注意：
> - 这是局域网模式，**电脑要开着、且不能换 Wi-Fi**。适合在家学习场景。
> - 想随时随地用 → 看方式二（部署到互联网，一劳永逸）。

---

## 方式二：部署到免费静态托管（随时随地说开就开）

`vocab-app` 文件夹本质是一个纯静态网站，可以免费部署到任一托管平台：

| 平台 | 特点 |
|------|------|
| Cloudflare Pages | 国内可访问，免费，操作简单（推荐） |
| GitHub Pages | 免费，国内访问时好时坏 |
| Vercel / Netlify | 免费，国内访问不稳定 |

以 Cloudflare Pages 为例：
1. 注册 cloudflare.com（免费）
2. 控制台 → Pages → 创建项目 → 直接上传 `vocab-app` 文件夹（拖拽上传即可，或连 Git 仓库）
3. 得到一个 `xxx.pages.dev` 网址
4. iPhone Safari 打开该网址 → 分享 → 添加到主屏幕

部署到 **https** 之后，Service Worker 离线缓存自动生效：**第一次打开后，断网也能背单词**，学习进度存在手机本地。还可以用「我的 → 导出学习数据」定期备份。

---

## 方式三：编译真正的原生 iOS App（需要苹果生态）

如果你未来拥有以下条件，可以随时把本项目打包成原生 iOS App：

- 一台 Mac（或云端 Mac 服务）
- Xcode（免费）
- Apple 开发者账号：免费账号可自签（7 天有效期，仅自己设备）；688 元/年账号可长期使用

技术路径：用 **Capacitor** 把 `vocab-app` 包装成原生工程（Android 端的 `vocab-android` 就是同样的思路，Capacitor 也有 iOS target）：
1. Mac 上 `npm install @capacitor/core @capacitor/cli && npx cap init`
2. 把 `vocab-app` 作为 webDir，`npx cap add ios`
3. Xcode 打开生成的工程 → 真机/模拟器运行 → 签名分发

安卓端我们已经在 Windows 上完成了这件事（见 `vocab-android` 与 APK），iOS 仅受苹果生态限制。

## 常见问题

- **添加到主屏幕后打开是白屏？** 电脑服务器没开（方式一）或托管站点失效（方式二），重新打开对应服务即可。
- **换了个 Wi-Fi 打不开了？** 局域网地址随路由器分配变化，重新查看 serve.py 窗口显示的手机地址。
- **学习进度会丢吗？** 进度存在 iPhone 本地（浏览器存储）。方式二 https 部署后较稳定；无论如何，建议偶尔用「我的 → 导出学习数据」备份一份 JSON。
- **发音没声音？** iOS 的 PWA 使用系统内置英文语音（Safari Web Speech），一般直接可用；首次需要点击一下发音按钮激活。
